  问题：LaTeX 数学公式没有被正确渲染，只是显示为纯文本。

  根本原因：
  1. Markdown 处理器将数学公式的定界符（\(, \), \[, \]）转换成了普通括号
  2. 数学公式在 Markdown 处理过程中被修改

  解决方案：
  使用"保护-恢复"模式：
  1. 保护阶段：在 Markdown 处理之前，用唯一占位符替换所有数学公式
  2. 处理阶段：正常进行 Markdown 到 HTML 的转换
  3. 恢复阶段：将占位符替换回原始数学公式，并添加样式包装
  4. 清理阶段：移除可能包裹数学公式的多余 <p> 标签

  现在的效果：
  - $E = mc^2$ → <span class="math-inline">$E = mc^2$</span>
  - $$...$$ → <div class="math-display">$$...$$</div>
  - \(...\) → <span class="math-inline">\(...\)</span>
  - \[...\] → <div class="math-display">\[...\]</div>

  MathJax 配置：
  - 配置了识别 $...$ 和 $$...$$ 作为行内和块级数学
  - 配置了识别 \(...\) 和 \[...\] 作为替代语法
  - 设置了忽略代码块的类，避免冲突

  现在当你打开 final_output_correct.html 在浏览器中，MathJax 会自动渲染所有数学

  🧠 核心代码解析（cli.py）

  1. 数学公式处理（最复杂的部分）

  # 问题：Markdown处理器会把 \( 变成 (，把 \[ 变成 [
  # 解决方案：先"保护"数学公式，处理完再"恢复"

  # 保护阶段：把数学公式换成临时标记
  # $E = mc^2$ → "MATH_abc123"
  # 这样Markdown处理器就不会破坏它

  # 恢复阶段：把临时标记换回原始公式
  # "MATH_abc123" → <span class="math-inline">$E = mc^2$</span>

  为什么这么复杂？
  - Markdown 原本不支持数学公式
  - 我们需要在 Markdown 处理前保护数学公式
  - 处理完后再恢复，并添加样式

  2. KaTeX 数学渲染

  <!-- 引入KaTeX库 -->
  <link rel="stylesheet" 
  href="https://cdn.jsdelivr.net/npm/katex@0.16.10/dist/katex.min.css">
  <script defer 
  src="https://cdn.jsdelivr.net/npm/katex@0.16.10/dist/katex.min.js"></script>

  <!-- 自动渲染配置 -->
  <script>
  renderMathInElement(document.body, {
      delimiters: [
          {left: '$$', right: '$$', display: true},    // 块级公式
          {left: '$', right: '$', display: false},     // 行内公式
          {left: '\\(', right: '\\)', display: false}, // 括号语法
          {left: '\\[', right: '\\]', display: true}   // 括号块级
      ]
  });
  </script>

  ## 🔧 技术亮点（为什么这样设计）

  ### 1. **数学公式保护机制**
  - 使用 UUID 生成唯一标记，避免冲突
  - 支持多种数学语法：`$...$`、`$$...$$`、`\(...)`、`\[...]`

  - 使用 `watchdog` 库监控文件变化
  - 文件保存后自动重新编译
  - 适合写文档时实时预览

  ```python
  try:
