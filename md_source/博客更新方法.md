# 博客更新方法

本项目使用的是自行编写的Markdown到HTML编译器，实现路径在`../md-compiler`，使用python实现，uv包管理器，这个编译器是100%由Claude Code编写的。

## 编译方法

在项目根目录运行：

```bash
python md-compiler/batch_compile.py
```

脚本从6个起点出发，递归编译所有链接的文章：

- `md_source/index.md` → `index.html`（CS板块）
- `md_source/musings.md` → `musings.html`（Musings板块）
- `md_source/math.md` → `math.html`（Math板块）
- `md_source/music.md` → `music.html`（Music板块）
- `md_source/storytelling.md` → `storytelling.html`（Storytelling板块）
- `md_source/PE.md` → `PE.html`（PE板块）

页面外壳（header、nav、CSS、KaTeX、highlight.js）由编译器自动包裹，根据文件深度自动调整相对路径。

## 导航栏

所有页面自动生成统一的7项导航栏：

```html
<nav>
  <a href="index.html">CS</a>
  <a href="about.html">About</a>
  <a href="musings.html">Musings</a>
  <a href="math.html">Math</a>
  <a href="music.html">Music</a>
  <a href="storytelling.html">Storytelling</a>
  <a href="PE.html">PE</a>
</nav>
```

**注意：** `about.html` 是手写的独立页面，不在编译流程中，需手动保持导航栏与其他页面一致。

## 新增板块

若要新增一个板块（例如"Photography"），需要：

1. 在 `md_source/` 下创建 `photography.md` 和 `Photography/` 目录
2. 在 `md-compiler/batch_compile.py` 中：
   - `compile_all()` 的 queue 中加入 `(MD_SOURCE / 'photography.md', ROOT / 'photography.html', DEFAULT_CSS)`
   - `parse_title_link()` 中加入 `elif str(rel) == 'photography.md': output_path = ROOT / 'photography.html'`
   - `render_shell()` 的 nav 中加入 `<a href="{prefix}photography.html">Photography</a>`
3. 手动更新 `about.html` 的导航栏
4. 运行编译

## 文章列表格式 `<posts-list>`

分类索引页和根页面中，用 `<posts-list>` 块列出子页面：

```markdown
<hr>
<h2>Posts</h2>

<posts-list>

<title-link>
css_source/main_style.css
Study Notes on Computer Architecture,计算机体系结构学习笔记
[2026-2-8](./CS/Computer-Architecture/index.md)
</title-link>

<title-link>
DNN Compiler,深度神经网络编译器
[2026-3-27](./CS/DNN-DSL-Compiler/index.md)
</title-link>

</posts-list>
```

**`<title-link>` 格式说明：**

- **第一行（可选）**：CSS样式路径，默认 `css_source/main_style.css`，也可用 `md-compiler/academic.css`
- **第二行（必填）**：`en-title, zh-title`，英文逗号分隔
- **第三行（必填）**：`[日期](./相对路径.md)`，标准markdown链接

编译器会自动生成带 `<table class="posts-list">` 的标准HTML列表，链接自动从 `.md` 转为 `.html`。

## git使用命令

查询删改：

git commit -m "提交信息"

推送到远程仓库
git push origin main

## "合作"

本项目我会在不同的电脑上推送，平常工位上的电脑会写工作的部分，自己用的电脑写学习的部分。此前从来没有做过Github合作项目，就在这里熟悉一下。

---

**初始化：**

在电脑上先克隆项目：
```bash
git clone https://github.com/AsukaZhenyu/AsukaZhenyu.github.io.git
cd AsukaZhenyu.github.io
```

每台电脑开发自己的分支：
```bash
git checkout -b win11
git push -u origin win11
```
还有：
```bash
git checkout -b arch
git push -u origin arch
```
`-u`将本地分支推送到远程仓库

---

**各个电脑的工作流：**

开始工作时获取最新版本：
```bash
git checkout win11
git fetch origin
git merge origin/main
```

工作结束后：
```bash
git add .
git commit -m "message"
git push origin win11
```

每台电脑都只修改自己的分支，拉去main分支，过了一段时间后，就可以在GitHub界面提交PR，将自己的分支融合到仓库的main分支。

合并本地main分支（当然也可以不维护本地main分支）：
```bash
git checkout main
git pull origin main
```
