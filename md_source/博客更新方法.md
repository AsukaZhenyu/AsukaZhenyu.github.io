# 博客更新方法

本项目使用Pandoc工具，将Markdown文件转换为HTML文件，直接部署在GitHub Pages上。

所以博客更新的流程就是在md_source文件夹下编写新的文章，运行Pandoc命令行，将markdown文件转为HTML，并把HTML文件放到合适的位置，最后更新index.html、classify.html、newest.html三个文件。

## Pandoc 常用命令

1. 查看Pandoc版本

```bash
pandoc --version
```

主要用于检测Pandoc是否安装成功。

2. 查看Pandoc信息

查看程序支持的输入文件格式

```bash
pandoc --list-input-formats
```

查看程序支持代码高亮的编程语言

```bash
pandoc --list-highlight-languages
```

帮助

```bash
pandoc --help
```

3. 将Markdown文件转换为HTML文件

```bash
pandoc -s input.md -o output.html
```
