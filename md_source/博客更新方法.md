# 博客更新方法

本项目使用的是自行编写的Markdown到HTML编译器，实现路径在`../md-compiler`，使用python实现，uv包管理器，这个编译器是100%由Claude Code编写的。



## git使用命令

查询删改：
git status

加入到 Git 的暂存区，准备提交
git add .

提交到本地仓库
git commit -m "提交信息"

推送到远程仓库
git push origin main

## “合作”

本项目我会在不同的电脑上推送，平常工位上的电脑会写工作的部分，自己用的电脑写学习的部分。此前从来没有做过Github合作项目，就在这里熟悉一下。

---

**初始化：**

在电脑上先克隆项目：
```bash
git clone https://github.com/AsukaZhenyu/AsukaZhenyu.github.io.git
cd AsukaZhenyu.github.io
```

每台电脑开发自己的分支：
```bash
git checkout -b win11
git push -u origin win11
```
还有：
```bash
git checkout -b arch
git push -u origin arch
```
`-u`将本地分支推送到远程仓库

---

**各个电脑的工作流：**

开始工作时获取最新版本：
```bash
git checkout win11
git fetch origin
git merge origin/main
```

工作结束后：
```bash
git add .
git commit -m "message"
git push origin win11
```

每台电脑都只修改自己的分支，拉去main分支，过了一段时间后，就可以在GitHub界面提交PR，将自己的分支融合到仓库的main分支。

合并本地main分支（当然也可以不维护本地main分支）：
```bash
git checkout main
git pull origin main
```
