# 博客更新方法

本项目使用的是自行编写的Markdown到HTML编译器，实现路径在`../md-compiler`，使用python实现，uv包管理器，这个编译器是100%由Claude Code编写的。

## 编译方法

在项目根目录运行：

```bash
python md-compiler/batch_compile.py
```

脚本从7个起点出发，递归编译所有链接的文章：

- `md_source/index.md` → `index.html`（About首页）
- `md_source/CS/index.md` → `html_source/CS/index.html`（CS板块）
- `md_source/Musings/index.md` → `html_source/Musings/index.html`（Musings板块）
- `md_source/Math/index.md` → `html_source/Math/index.html`（Math板块）
- `md_source/Music/index.md` → `html_source/Music/index.html`（Music板块）
- `md_source/Storytelling/index.md` → `html_source/Storytelling/index.html`（Storytelling板块）
- `md_source/PE/index.md` → `html_source/PE/index.html`（PE板块）

页面外壳（header、nav、CSS、KaTeX、highlight.js）由编译器自动包裹，根据文件深度自动调整相对路径。

## 导航栏

所有页面自动生成统一的7项导航栏：


## 新增板块

若要新增一个板块（例如"Photography"），需要：

1. 在 `md_source/` 下创建 `Photography/index.md`（板块根页面）和文章目录
2. 在 `md-compiler/batch_compile.py` 中：
   - `compile_all()` 的 queue 中加入起点：
     `(MD_SOURCE / 'Photography' / 'index.md', HTML_SOURCE / 'Photography' / 'index.html', DEFAULT_CSS)`
   - `render_shell()` 的 nav 中加入 `<a href="{prefix}html_source/Photography/index.html">Photography</a>`
3. 运行编译

## 文章列表格式 `<posts-list>`

分类索引页和根页面中，用 `<posts-list>` 块列出子页面。

### 链接 `.md` 文件（编译）

```markdown
<hr>
<h2>Posts</h2>

<posts-list>

<title-link>
css_source/main_style.css
Study Notes on Computer Architecture,计算机体系结构学习笔记
[2026-2-8](./CS/Computer-Architecture/index.md)
</title-link>

<title-link>
DNN Compiler,深度神经网络编译器
[2026-3-27](./CS/DNN-DSL-Compiler/index.md)
</title-link>

</posts-list>
```

### 链接 `.html` 文件（直接复制）

如果 `<title-link>` 链接的是 `.html` 文件，编译器不会编译它，而是**将文件及其同目录下所有配套文件（JS、CSS、图片等）直接复制到 `html_source/`**。这适用于预制 HTML 页面。

```markdown
<title-link>
css_source/main_style.css
Basic Music Theory,基础乐理
[2026-8-9](./Music/Basic-Music-Theory/index.html)
</title-link>
```

`md_source/Music/Basic-Music-Theory/` 下的所有非 `.md` 文件都会被复制到 `html_source/Music/Basic-Music-Theory/`。

### `<title-link>` 格式说明：

- **第一行（可选）**：CSS样式路径，默认 `css_source/main_style.css`，也可用 `md-compiler/academic.css`
- **第二行（必填）**：`en-title, zh-title`，英文逗号分隔
- **第三行（必填）**：`[日期](./相对路径.md)` 或 `[日期](./相对路径.html)`，标准markdown链接

编译器会自动生成带 `<table class="posts-list">` 的标准HTML列表。`.md` 链接自动转为 `.html`；`.html` 链接原样保留。

## 目录 `[toc]`

在文章开头加入 `[toc]`（大小写均可），编译器会自动：

1. 从正文 h1-h3 标题生成**左侧树形目录**
2. 目录 sticky 跟随滚动，支持点击跳转
3. 浏览正文时目录自动高亮当前标题（IntersectionObserver 滚动监听）
4. 窄屏（<900px）自动隐藏侧边栏

```markdown
# 文章标题

[toc]

## 第一节
内容...

### 小节 1.1
内容...

## 第二节
内容...
```

没有 `[toc]` 标记的页面保持全宽布局。

## 正文样式

### 标题层级

| 层级 | 字号 | 样式 |
|------|------|------|
| h1 | 26px | 加粗黑色，底部分隔线 |
| h2 | 21px | 加粗黑色，上方大留白 |
| h3 | 17px | 加粗黑色，左侧竖线缩进 |

### 表格

`<table>` 自动渲染为带边框的表格：全宽、浅灰表头、偶数行微灰底色。

### 图片

`<img>` 自动限制最大宽度 100%，居中显示，不超出内容区域。

## git使用命令

## "合作"

本项目我会在不同的电脑上推送，平常工位上的电脑会写工作的部分，自己用的电脑写学习的部分。此前从来没有做过Github合作项目，就在这里熟悉一下。

---

**初始化：**

在电脑上先克隆项目：
```bash
git clone https://github.com/AsukaZhenyu/AsukaZhenyu.github.io.git
cd AsukaZhenyu.github.io
```

每台电脑开发自己的分支：
```bash
git checkout -b win11
git push -u origin win11
```
还有：
```bash
git checkout -b arch
git push -u origin arch
```
`-u`将本地分支推送到远程仓库

---

**各个电脑的工作流：**

开始工作时获取最新版本：
```bash
git checkout win11
git fetch origin
git merge origin/main
```

工作结束后：
```bash
git add .
git commit -m "message"
git push origin win11
```

每台电脑都只修改自己的分支，拉去main分支，过了一段时间后，就可以在GitHub界面提交PR，将自己的分支融合到仓库的main分支。

合并本地main分支（当然也可以不维护本地main分支）：
```bash
git checkout main
git pull origin main
```
