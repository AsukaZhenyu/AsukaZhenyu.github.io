# 博客更新方法

本项目使用的是自行编写的Markdown到HTML编译器，实现路径在`../md-compiler`，使用python实现，uv包管理器，这个编译器是100%由Claude Code编写的。

## 编译方法

在项目根目录运行：

```bash
python md-compiler/batch_compile.py
```

脚本从 `md_source/index.md` 和 `md_source/musings.md` 出发，递归编译所有链接的文章。页面外壳（header、nav、CSS、KaTeX、highlight.js）由编译器自动包裹，根据文件深度自动调整相对路径。

## 文件结构

```
md_source/
├── index.md              # 根页面，列出所有分类（除Musings）
├── musings.md            # 列出 Musings/ 下所有文章
├── 分类目录/
│   ├── index.md          # 分类索引页，列出同目录下文章
│   └── 文章.md           # 具体文章
└── Musings/
    └── 文章.md           # 随笔文章（由musings.md直接链接）
```

## 文章列表格式 `<posts-list>`

分类索引页和根页面中，用 `<posts-list>` 块列出子页面：

```markdown
<hr>
<h2>Posts</h2>

<posts-list>

<title-link>
css_source/main_style.css
Study Notes on Computer Architecture,计算机体系结构学习笔记
[2026-2-8](./Computer-Architecture/index.md)
</title-link>

<title-link>
DNN Compiler,深度神经网络编译器
[2026-3-27](./DNN-DSL-Compiler/index.md)
</title-link>

</posts-list>
```

**`<title-link>` 格式说明：**

- **第一行（可选）**：CSS样式路径，默认 `css_source/main_style.css`，也可用 `md-compiler/academic.css`
- **第二行（必填）**：`en-title, zh-title`，英文逗号分隔
- **第三行（必填）**：`[日期](./相对路径.md)`，标准markdown链接

编译器会自动生成带 `<table class="posts-list">` 的标准HTML列表，链接自动从 `.md` 转为 `.html`。

## git使用命令

查询删改：
git status

加入到 Git 的暂存区，准备提交
git add .

提交到本地仓库
git commit -m "提交信息"

推送到远程仓库
git push origin main

## “合作”

本项目我会在不同的电脑上推送，平常工位上的电脑会写工作的部分，自己用的电脑写学习的部分。此前从来没有做过Github合作项目，就在这里熟悉一下。

---

**初始化：**

在电脑上先克隆项目：
```bash
git clone https://github.com/AsukaZhenyu/AsukaZhenyu.github.io.git
cd AsukaZhenyu.github.io
```

每台电脑开发自己的分支：
```bash
git checkout -b win11
git push -u origin win11
```
还有：
```bash
git checkout -b arch
git push -u origin arch
```
`-u`将本地分支推送到远程仓库

---

**各个电脑的工作流：**

开始工作时获取最新版本：
```bash
git checkout win11
git fetch origin
git merge origin/main
```

工作结束后：
```bash
git add .
git commit -m "message"
git push origin win11
```

每台电脑都只修改自己的分支，拉去main分支，过了一段时间后，就可以在GitHub界面提交PR，将自己的分支融合到仓库的main分支。

合并本地main分支（当然也可以不维护本地main分支）：
```bash
git checkout main
git pull origin main
```
