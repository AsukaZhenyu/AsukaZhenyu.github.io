## 常用算法

### 二分

**问题1**：对于整数数列a，求$(a[i]+a[j])\%p$前k个最大值。

难点是取模，求**第k个最大值可以用二分法解决**，求前k个最大值可以利用第k个最大值。

```c++
// 首先对数组取模加排序
for(int i=0;i<n;i++){
    cin>>a[i];
    a[i]%=p;
}
sort(a.begin(),a.end());
// 使用双指针计算大于x的(a[i]+a[j])%p的个数
// 核心思想 1. 计算(a[i]+a[j])>=x，记为work(x) 
// 2. 答案是 work(x)-work(p)+work(p+x)

auto work=[&](int x){
    long long ans=0;
    for(int i=0,j=n-1;i<n;i++){
        while(j>=0&&(a[i]+a[j])>=x) j--;
        if(j>i) ans+=n-1-j;
        else ans+=n-1-i;
    }
    return ans;
}
auto check=[&](int x){
    return work(x)-work(p)+work(p+x);
}
// 二分查找第k个最大值
int l=0,r=p-1;
while(l<=r){
    int mid=(l+r)/2;
    if(check(mid)>=k) l=mid+1;
    else r=mid-1;
}
```

### 倍增

和快速幂的思想相似，和二进制的思想相似。


[3534](https://leetcode.cn/problems/path-existence-queries-in-a-graph-ii/) $|nums[i] - nums[j]| \leq maxDiff$时i和j连通，给定一组查询判断两个节点是否连通，如果连通给出节点之间的最短距离。

贪心思路：对于节点l,r，表示i和j中较小和较大的权重，贪心的思路是每次从l向右跳最远的距离，直到大于等于r，记录此时的跳的步数就是答案，否则就不连通。

思路前推：因为连接性只与数值大小有关，对于一大一小两个权值的连接，最少步数要求每次迈最长。

思路后推：一步一步地后推，时间复杂度是$O(n)$，这时利用倍增的思想，时间复杂度是$O(\log n)$。

倍增形式：`pa[i][j]`表示从i开始跳$2^j$步的终点，先初始化`pa[i][0]`，然后利用`pa[i][0]`初始化`pa[i][1]`，以此类推。类似于动态规划，或者ST表的构建。

```c++
class Solution {
public:
    vector<int> pathExistenceQueries(int n, vector<int>& nums,
     int maxDiff, vector<vector<int>>& queries) {
        vector<int> id(n);
        ranges::iota(id,0);
        sort(id.begin(),id.end(),[&](int& a,int& b){
            return nums[a]<nums[b];
        });

        vector<int> rank(n);
        for(int i=0;i<n;i++){
            rank[id[i]]=i;
        }
        int mx=__lg(n)+1;
        vector nl(n,vector<int> (mx));
        int left=0;
        for(int i=0;i<n;i++){
            while(nums[id[i]]-nums[id[left]]>maxDiff){
                left++;
            }
            nl[i][0]=left;
        }
        for(int i=0;i<mx-1;i++){
            for(int x=0;x<n;x++){
                int p=nl[x][i];
                nl[x][i+1]=nl[p][i];
            }
        }

        vector<int> ans(queries.size());
        for(int qi=0;qi<queries.size();qi++){
            int l=queries[qi][0],r=queries[qi][1];
            if(l==r) continue;
            l=rank[l];r=rank[r];
            if(l>r) swap(l,r);
            int res=0;
            for(int k=mx-1;k>=0;k--){
                if(nl[r][k]>l){
                    res|=(1<<k);
                    r=nl[r][k];
                }
            }
            ans[qi]=nl[r][0]>l?-1:res+1;
        }
        return ans;
    }
};
```

class Solution:
    def maxSubarrays(self, nums: List[int]) -> int:
        ans = 0
        a = -1  # -1 就是 111...1，和任何数 AND 都等于那个数
        for x in nums:
            a &= x
            if a == 0:
                ans += 1  # 分割

16. 如果要遍历一个数组，对每个元素外的所有元素操作的结果。考虑前后缀分解，也就是预处理所有的前后缀，在实际操作中可以只处理后缀，前缀在遍历的时候处理。用空间换时间。
直接模拟的写法：
```c++
for(int i=0;i<stop;i++){
    long long mid=(((long long)nums[i])<<k)|base;
    for(int j=0;j<stop;j++){
        if(j==i) continue;
        mid|=nums[j];
    }
    ans=max(ans,mid);
}
```
前后缀分解写法：
```c++
vector<int> suf(stop+1);
for(int i=stop-1;i>=0;i--){
    suf[i]=suf[i+1]|nums[i];
}
int pre=0;
for(int i=0;i<stop;i++){
    long long mid=(((long long)nums[i])<<k)|base|suf[i+1]|pre;
    pre|=nums[i];
    ans=max(ans,mid);
}
```
