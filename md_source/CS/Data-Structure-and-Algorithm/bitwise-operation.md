# 位运算

1. 异或^ :
单位元e=0 即有：a\^0=0\^a=a 同时还有：a\^a=0
从0到n的所有元素的异或值：
```c++
int xor_n(int n) {
    switch (n % 4) {
        case 0: return n;
        case 1: return 1;
        case 2: return n + 1;
        default: return 0;
    }
}
```
2. 位掩码0x5555555555对应二进制中的0101_0101_0101……，一个16进制位对应4个二进制位。所以int32位对应掩码的长度8。
3. 位运算的优先度较低
```c++
return n&(n-1)==0;
//“==”优先度大于“&”，所以正确写法是对限免整个部分加上括号。
return (n&(n-1))==0;
```
4. 位运算应该防止溢出
```c++
int res=(1<<31)-1; //会溢出
long long res=(1ll<<31)-1;
```

6. 判断二进制是否是**01交替**：
```c++
long a=n^(n>>1);
return (a&(a+1))==0;
```
判断是否有两个相邻的1：
```c++
if(x&(x>>1)==0) return true; //此时没有相邻的1
//如果要判断是否没有相邻的0，只需要将x取反即可。
//这里的取反不要直接用~，可以和 长为len的11111…… 进行异或操作。
```

7. 要满足a|b=c需要对a,b反转几个位
```c++
int y1= c ^ (a | b);//不同的位，计算一次
int y0= ~c & a & b;//a,b重复的不同的，再计算一次
return __builtin_popcount(y0) + __builtin_popcount(y1);
```
8. 与运算&越运算越小
    下面给出一些贪心的思路
    case1：&值最大的子数组（连续），一定是若干 连续的数组中的最大值 。
    case2：子数组/子序列最小的&值，一定是全部求&。
    case3：如果一堆数的&是0，任选两个出来的&也一定是0
    case4：考虑处理后的最大值，不妨从最高位入手。
