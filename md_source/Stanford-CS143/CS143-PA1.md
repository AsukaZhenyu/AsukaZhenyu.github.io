## PA1 Stack Machine

虚拟机里没有PA1相关的文档，你可以通过上面提到的方法下载课程文件，里面的handouts文件夹里有Cool语言的参考和各个作业的文档，还包括Stanford版本的作业5额外作业的文档。handouts文件夹我也上传到北航云盘里了。

关于Cool语言的文档也可以通过课程官网下载（推荐，因为可能会更新修正错误），从官网上你可以下载到三分cool相关文档，分别是：cool-manual、cool-tour、cool-runtime。cool-manual是语法规范，分为不规范定义和规范定义两个部分，cool-tour是Cool编译器支持代码的说明，方便我们编写编译器，cool-runtime是cool的runtime系统介绍，主要用于MIPS汇编代码生成。

对于PA1，你需要看的是cool-manual和example里的示例代码。cool-manual里的informal部分介绍了Cool语言的语法，基本类，基本运算，理论上看了informal部分就可以写代码了，formal部分主要介绍了类型检查和表达式计算的推演逻辑，formal部分推演和使用的符号是基于informal部分的，并且自定义了很多表示符号，你需要仔细阅读符号和运算的定义。

下面是我总结的一部分Cool语言的要领：

1. 单行注释: `--`，多行注释：`(**)`

2. 一个Cool文件由多个类构成，一个Cool程序必须要有Main类，其中必须要有main方法。Cool类里面有属性和方法，所有的属性都不能从外面访问，所有的方法都可以从外面访问。

3. Cool是表达式语言，每个表达式都有值和类型。在方法中没有`return`而是返回最后一个表达式的值。

4. 基础类：Object、IO、String、Int、Bool，接口参考manual的8节，布尔常量是`true`、`false`，Int常量是无符号整数，允许有前导零，字符串常量要用双引号括起来。

5. Cool只能继承一个父类，在方法调用（dispatch）中，默认调用子类实现的方法（也可以通过静态调用父类实现），类内不允许定义相同方法，继承可以重新定义相同方法，无论是继承还是类内都不允许定义相同属性，但属性可以与方法名字相同。如果类不指定继承类，则默认为Object类。类名要以大写开头。

6. SELF_TYPE作用是：在父类里使用SELF_TYPE，在子类中继承，在其他调用时，返回的类型依据你声明的类型确定，不会再父类定义时就确定好。

7. 方法在定义时要求有`{expr}`，注意和块区分，一旦函数里有多个语句，这里就要用到两个花括号，但是如果只有一个语句就不能加两个花括号，或者最后加一个`;`。这就是为什么会有下面的写法：
```java
head()  : Int { { abort(); 0; } };
```

8. 没有返回值或者或者很多if的逻辑，返回值类型设为Object即可。

9. 对于IF-ELSE中间空的部分，可以加一个new Object，什么都没有的话会报错。

10. 对象在使用前一定要new，不然会产生dispatch void的错误。

PA1要编写一个栈机器，输入可以是无符号整数，`s`，`+`，`e`、`d`、`s`，如果输入是无符号整数、`+`、`s`则直接放入栈中，如果输入是`d`则把栈中所有内容打印出来，如果输入是`e`则分两种情况，如果栈顶是`+`则把`+`弹出后，对栈顶两个数做加法然后放入，如果栈顶是`s`则把`s`弹出后，交换栈顶的两个元素。

因为没有数组，需要我们自己实现相关数据结构，我看在example里大部分代码使用的都是链表数据结构，我直接参考里面的list.cl文件，使用链表实现。

最后简单说一下，PA1文档里说命令前有'>'但是如果你运行`make test`输入没有'>'，区别就是Main类里get_cmd函数。下面直接给stack.cl的代码：

```java
class List{
   isNil() : Bool {true};
   head() : String {{abort();"";}};
   tail() : List {{abort();self;}};
   cons(x : String) : List {
      (new Cons).init(x,self)
   };
};
class Cons inherits List {
   car : String;
   cdr : List;

   init(x : String, y : List) : List {{
      car <- x;
      cdr <- y;
      self;
   }};

   isNil() : Bool {false};
   head() : String {car};
   tail() : List {cdr};
};
class Stack inherits IO{

   st : List <- new List;
   z : A2I <- new A2I;

   get_list() : List {st};

   -- int,+,s
   push(x : String) : Object {
      {
         st <- st.cons(x);
      }
   };
   -- e

      pop() : Object {
      if st.isNil() then new Object else
         (let top:String <- st.head() in
            if top = "+" then
               {
                  -- pop and add
                  st <- st.tail();
                  st <- st.tail().tail().cons(z.i2a(z.a2i(st.head())+z.a2i(st.tail().head())));
               }
            else 
               if top = "s" then
                  {
                     -- pop and swap
                     st <- st.tail();
                     st <- st.tail().tail().cons(st.head()).cons(st.tail().head());
                  }
               else new Object fi -- do nothing
            fi
         )
      fi
   };
};
class Main inherits IO {

   st : Stack <- new Stack;
   cmd : String;

   get_cmd() : String {{
      cmd <- in_string();
      cmd <- cmd.substr(1,cmd.length()-1);
   }};
   print_list(l : List) : Object {
      if l.isNil() then out_string("\n") else
         {
            out_string(l.head());
            out_string("\n");
            print_list(l.tail());
         } fi
   };
   main() : Object {{
      -- out_string("Nothing implemented\n")
      while (get_cmd()="x")=false loop
      
         if cmd = "s" then st.push(cmd) else
         if cmd = "+" then st.push(cmd) else
         if cmd = "e" then st.pop() else
         if cmd = "d" then print_list(st.get_list()) else
         st.push(cmd) fi fi fi fi

      
      pool;
      -- elegant exit
      -- st.abort();
      -- cmd.abort();
      -- abort()
   }};

};
```
