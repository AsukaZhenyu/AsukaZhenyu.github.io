## 打擂台

思考如何得出三个数的最大值
```c++
max(a,max(b,c));
```
那如何得出一个数组的最大值，显然这是$O(n)$的复杂度能够解决的。
```c++
int max=-1;
for(num:nums) max=max(max,num);
```

那现在来思考这道题：

[2923. 找到冠军 I](https://leetcode.cn/problems/find-champion-i/)
在图论关系中，怎么找到最大值？
最自然的思路：遍历每一个个体，每一个个体在去遍历其他个体，看看它是不是最强的。这是$O(n^2)$的复杂度。但是如果想到上述打擂台的思路，其实可以化成$O(n)$的复杂度。

上述的“打擂台思路”其实是一种充分利用数据的体现，减少比较的次数，某种程度上和DP的思想有些像？`dp[i+1]=max(dp[i],nums[i+1])`

只不过这道题比较方法是“新定义”的，或者说是图论的。
