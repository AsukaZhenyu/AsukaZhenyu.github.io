## 贪心

### 中位数贪心
- **问题**：
给定数组，每次操作可以把其中一个数加一/减一，把所有数都变成一样的，**最少操作**多少次？

- **变式**：
数轴上有许多村庄，要建一个邮局，使得所有村庄到邮局的距离之和最小，**最小距离**和是多少？

- **结论**：
把所有数都变成中位数，操作次数最少。

- **证明思路**：
像剥洋葱一样，一层一层把外围去掉，得到最优解就是中位数。

### 构造排列
- **问题**：
构造一个长度为n的排列，使得第i个位置上的数在[$l_i$, $r_i$]区间中。

- **思路**：
第一次做的时候想到了可以对区间要求[$l_i$, $r_i$]进行**排序**，将1-n依次放入。但实际上符合要求的构造方法的区间排序不能单靠左右端点大小进行，反例：
`[1, 1] [1, 4] [2, 2] [3, 3]` 
**贪心思路**：对于数字i，必然放在某个[$l_i$, $r_i$]，对于所有满足条件的区间，i选择右端点最小的区间，用一个优先队列维护左端点满足要求的区间，若优先队列为空则不存在满足条件的排列，每次取出右端点最小的区间，若右端点不满足条件则放弃该区间（不应该有区间被放弃，故此时不存在满足条件的排列）。
```cpp
vector<array<int,3>> a(n);
int pt=0;
for(auto& [l,r,i]:a){
    cin>>l>>r;
    i=++pt;
}
sort(a.begin(),a.end());
set<array<int,3>> pq; // {r,l,i} 用set维护有序数组，每次要取出最小的右端点
vector<int> ans(n+1);
int ptr=-1; // 遍历区间
for(int i=0;i<=n;i++){
    // 寻找每个数i对应的区间
    while(ptr+1<n&&a[ptr+1][0]<=i){
        ptr++;
        pq.insert({a[ptr][1],a[ptr][0],a[ptr][2]});
    }
    // 判断是否有满足条件的左端点
    if(pq.empty()){
        cout<<"NO\n";
        return 0;
    }
    auto [r,l,id]=*pq.begin();
    pq.erase(pq.begin());
    // 判断右端点是否满足条件
    if(r<i){
        cout<<"NO\n";
        return 0;
    }
    ans[id]=i;
}
```

8. [Problem - 1971G - Codeforces](https://codeforces.com/problemset/problem/1971/G)

   只有**异或小于4**的两个值才能交换位置。这意味着第三位即以前的所有位必须一样，一样的才能互换位置，这里用哈希表加堆实现了**分组排序**。

   问题是为什么用unordered_map会TLE但是map不会？
   ```c++
   void solve(){
       int n;
       cin>>n;
       //分组排序
   	map<int,priority_queue<int>> m;
   	vector<int> a(n);
   	for(int i=0;i<n;i++){
    		cin>>a[i];
   		m[a[i]>>2].push(-a[i]);
   	} 
   	for(int i=0;i<n;i++){
   		cout<<-m[a[i]>>2].top();
   		m[a[i]>>2].pop();
   		if(i<n-1) cout<<" ";
   		else cout<<"\n";
   	}
   } 
   ```

11. [3086. 拾起 K 个 1 需要的最少行动次数](https://leetcode.cn/problems/minimum-moves-to-pick-k-ones/)

    中位数贪心，**货仓选址**，使所有元素全部相等的最小操作次数

    选择中位数（从两边向内看，仓址被限定在最中间，也就是中位数。）这里不是数学上严格的中位数，偶数情况下左边或右边都可以。

    最小距离的计算：前缀和（前提是pos递增）$O(1)$
    ```python
    pre_sum = list(accumulate(pos, initial=0))
    
    left=0
    right=n #pos取值范围[left,right),n=len(pos)
    i=left+(right-left)//2 #最小距离仓址
    #i=bisect_left(pos,target) #到给定仓址的总距离，首个大于等于target的下标
    s1=pos[i]*(i-left)-(pre_sum[i]-pre_sum[left])
    s2=pre_sum[right]-pre_sum[i]-pos[i]*(right-i)
    min_length=s1+s2
    ```
