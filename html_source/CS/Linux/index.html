Using the Linux Operating System

之前做深度学习项目的时候，需要租用远程服务器进行训练，在autodl服务器里使用Linux配置环境、运行代码后有一种非常清晰的感觉。之前用VS和Pycharm的时候，不太明白代码是如何运行的，出现问题了也觉得一头雾水。有了Linux“开发”的初体验后，这种清晰的控制方式让我非常着迷，之后我想在win本地复制这种“开发”体验，目前用VS Code+WSL非常爽。

正好家里有一台老电脑，现在运行win10上的GUI文件管理器都非常卡顿，想着重装Linux系统让它焕发新生，实际使用和学习Linux，增加我的操作系统使用经验。装个Arch Linux，做做RICE，平常就用来编辑文件，学学rust、go，写点玩具项目，还可以在这上面做一做课程的lab。我个人认为在win上管理开发环境非常麻烦，现在的主力机就做verilog和fpga。
